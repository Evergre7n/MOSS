# MOSS — contribution materials for DS Bot upstream

This public repository holds pull-request drafts and sanitized patch notes for the DS Bot upstream project.

Every file is reviewed word by word before publication. No credentials, account identifiers, machine-specific paths, conversation data or internal project names are included, and no materials reference or link to any private repository.

## Contents

- `PR-DRAFT.md` — pull request body, grouped by function
- `PATCH-INVENTORY.md` — functional inventory of the proposed patches

## Status

Draft stage. Source files are published only after the draft has been reviewed and each file has passed the word-by-word disclosure check.
